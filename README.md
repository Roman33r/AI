# AI / 52

Русскоязычная интерактивная программа обучения AI-инжинирингу с нуля: 53 учебные недели (0–52), восемь этапов и один сквозной проект — **Neuro/52, собственная полноценная нейросеть**.

## Результат курса

Выпускник создаёт не набор несвязанных упражнений, а единый репозиторий с нейросетью для распознавания рукописных цифр MNIST:

- собственные тензорные и матричные операции на Python и NumPy;
- forward pass и backpropagation без готового NN-фреймворка в ядре;
- полносвязная сеть, softmax, cross-entropy, градиентные проверки;
- собственные optimizers, регуляризация, training loop и checkpoints;
- расширения Conv2D, Embedding и Attention;
- воспроизводимые эксперименты, метрики, error analysis и model card;
- FastAPI, Docker, CI/CD, мониторинг и публичный inference;
- веб-интерфейс, в котором пользователь рисует цифру и получает вероятности классов;
- необязательный LLM-ассистент для объяснений и диагностики, который не заменяет собственную нейросеть.

PyTorch используется только как независимый ориентир для проверки вычислений и сравнения экспериментов, а не как замена собственной реализации.

## Как проект растёт по этапам

| Этап | Недели | Результат в Neuro/52 |
| --- | --- | --- |
| Старт | 0 | Репозиторий и каркас будущей нейросети |
| Python | 1–8 | Нейрон, математическое ядро, NumPy-движок и первый inference |
| ML | 9–16 | Обученный SoftmaxClassifier, baseline, метрики и Neuro/52 v0.1 |
| Deep Learning | 17–24 | Свой backpropagation, MLP, CNN, embeddings, attention и Neuro/52 v1.0 |
| LLM | 25–34 | Ассистент, retrieval, tools, distillation, evaluation и безопасность |
| MLOps | 35–42 | API, контейнеры, очереди, облако, CI/CD и наблюдаемость |
| Проект | 43–48 | Улучшенный checkpoint, веб-приложение и Neuro/52 v2.0 |
| Карьера | 49–52 | Портфолио, защита кода и развитие проекта после курса |

У каждой недели есть проектный артефакт, список файлов, четыре шага реализации, практическое задание и критерий готовности. Подробная теория, формулы, схемы, код и разобранные примеры остаются внутри учебных материалов.

## Возможности сайта

- полный учебный материал в каждой из 53 недель;
- сквозная дорожная карта Neuro/52 и проектный шаг внутри каждого урока;
- самопроверка с объяснением ответов и смешанные тесты по разным этапам;
- карточки повторения и отдельная колода сложных понятий;
- поиск по темам и определениям, фильтры по этапам и статусу;
- таймер фокуса, недельная цель, график активности и прогресс по этапам;
- локальные заметки, светлая и тёмная темы;
- экспорт и импорт резервной копии прогресса в JSON;
- установка как PWA и работа интерфейса после первого сетевого посещения.

**Важно:** прогресс хранится только в `localStorage` текущего браузера. Синхронизации между устройствами нет. Для переноса используйте экспорт/импорт JSON на странице «Прогресс».

## Запуск локально

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Vite откроет сайт на `http://localhost:3000`.

## Production-сборка

```bash
npm run build
npm run preview
```

Готовые статические файлы появятся в `dist/`. Относительный `base` позволяет размещать проект в подпапке GitHub Pages.

## GitHub Pages

Репозиторий: <https://github.com/Roman33r/AI>

Workflow `.github/workflows/deploy.yml` собирает проект и публикует `dist/` после отправки изменений в ветку `main`. В настройках репозитория выберите **Settings → Pages → Build and deployment → Source → GitHub Actions**.

После успешного запуска workflow сайт будет доступен по адресу:

<https://roman33r.github.io/AI/>

Публикацию запускает GitHub после появления коммита в репозитории; сохранение локальных файлов само по себе сайт не публикует.

## Структура

- `src/data/project-plan.ts` — 53 последовательных проектных шага Neuro/52;
- `src/data/` — теоретические темы недель, этапы, ресурсы и типы;
- `src/lessons/` — индивидуальные подробные руководства недель 0–52 и структурированные обучающие блоки;
- `src/components/LessonMaterial.tsx` — отображение проектного шага, учебника, формул, схем, графиков, таблиц и кода;
- `src/components/` — урок, тесты, повторение, прогресс, навигация и таймер;
- `src/lib/progress.ts` — локальное сохранение, критерии завершения, импорт и экспорт;
- `src/lib/quiz.ts` — детерминированная генерация вопросов;
- `public/icons/` — иконки PWA;
- `.github/workflows/deploy.yml` — публикация на GitHub Pages.
